# VVintage — Product Card (Vite + Tailwind CSS)

Учебный проект: пересборка компонента «карточка товара» из проекта 
[VVintage](https://github.com/Nattyme/vvintage) на современном стеке 
**Vite + Tailwind CSS**.

## Цель проекта
- Освоить сборщик **Vite** (запуск, HMR, production-сборка).
- Познакомиться с **Tailwind CSS** (утилитарные классы, адаптив).
- Показать, как один и тот же UI можно реализовать на разных стеках 
  (Gulp + SCSS → Vite + Tailwind).

## Стек
- HTML5
- Tailwind CSS
- Vite
- npm

## Что реализовано
- Карточка товара: изображение, название, бренд, цена, кнопка.
- Hover-эффекты и переходы.
- Сборка через Vite (`npm run dev`, `npm run build`).
